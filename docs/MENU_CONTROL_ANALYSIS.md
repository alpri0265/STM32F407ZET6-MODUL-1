# Аналіз керування меню (BRINGUP_MODE)

## Що реально використовується

Меню керується **лише модулем encoder_menu** (`Src/encoder_menu.c`). Він опитує три піни **як три окремі кнопки** (з дебаунсом 35 мс):

| Пін   | Сигнал   | Дія в коді     | Умова «натиснуто» |
|-------|----------|----------------|--------------------|
| PB12  | MPG_A    | CCW («вгору»)  | **LOW** (підтяжка вгору, кнопка → GND) |
| PB13  | MPG_B    | CW («вниз»)    | **LOW** |
| PB14  | MPG_BTN  | Enter          | **HIGH** (`MENU_BTN_ENTER_ACTIVE_HIGH=1`) |

- На **списках** (Головне меню, Feed, Settings, Diagnostics): CW = наступний пункт, CCW = попередній, Enter = вхід.
- На екранах **Jog / Feed Auto / SL test**: лише **CCW** викликає вихід назад (`menu_back()`); CW і Enter не виходять.
- На **інших INFO-екранах** (Limits, Axis X, тощо): будь-яка дія (CW, CCW або Enter) = вихід назад.

Тобто **«енкодер меню»** у поточному коді — це саме **три кнопки**: вгору (PB12), вниз (PB13), вибір (PB14). Жодного читання кроків квадретури для меню немає.

## Що не використовується для меню

Модуль **enc_if** (`bsp/enc_if.c`) — це **квадретурний декодер** тих самих пінів PB12 (A), PB13 (B). Він викликається з TIM6 кожні 1 мс (`enc_if_poll_1ms()`), тобто обертання ручки енкодера перетворюється на кроки CW/CCW у змінній `enc_pending`. Але **жоден код не викликає `enc_if_take_encoder_step()`** — тобто результат декодера **ніде не використовується**. Для меню завжди беруться лише стани кнопок із `encoder_menu.c`.

Підсумок: якщо підключено **роторний енкодер** (наприклад EC11), обертання дає короткі імпульси на S1/S2. Щоб спрацювала «кнопка вгору» (CCW), пін PB12 має бути у стані LOW **щонайменше 35 мс**. Тому швидке обертання може не давати стабільного «вгору/вниз», а поводитися як одна кнопка або пропускати кроки. Для передбачуваної роботи з роторним енкодером потрібно було б у `encoder_menu_process()` додати читання `enc_if_take_encoder_step()` і встановлювати дію CW/CCW від нього.

## Джойстик і рух по осях

Рух по осях X/Z на екрані **Jog** керується **джойстиком** (PC2–PC5), а не MPG. На тому ж екрані в коді є також режим «кнопки меню = кроки» (PB12/PB13/PB14 як Up/Down/Enter для вибору осі та кроку) — це окремий варіант керування джогом, не навігація по меню.

## Рекомендація для PINOUT

У документації однозначно вказувати: керування меню = **три кнопки** на PB12, PB13, PB14; «вгору/назад» = **PB12 у стані LOW** (утримання ≥35 мс). Якщо використовується роторний енкодер — напрямок «назад» залежить від того, який контакт (S1 чи S2) підключено до PB12 і як довго він у низькому стані.
