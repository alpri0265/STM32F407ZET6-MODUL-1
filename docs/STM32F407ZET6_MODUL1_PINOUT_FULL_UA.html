Повна розпіновка проєкту STM32F407ZET6-MODUL-1

Джерело: Inc/main.h (символи CubeMX), Inc/board.h (пульт ZSY1474), ініціалізація Src/main.c.
МК: STM32F407ZET6. Документ описує основну гілку з каталогу Src/; файл Core/Inc/main.h майже збігається (порядок #define може відрізнятися).

Конфлікт пінів: якщо увімкнено MANUAL_FEED_USE_PENDANT_AXIS_SWITCH і MANUAL_FEED_PENDANT_AXIS_NEED_Y4 != 0 у board.h, піни PA2 і PA3 стають входами осей пульта Y / 4 — функції TEMP_ADC та SPINDLE_PWM на цих ногах у такій конфігурації не використовуються.

PA2 / PA3 не обов’язкові. Якщо дроти пульта Y і 4 ви не підключаєте, у Inc/board.h задайте #define MANUAL_FEED_PENDANT_AXIS_NEED_Y4 0 (при увімкненому MANUAL_FEED_USE_PENDANT_AXIS_SWITCH). Тоді прошивка не очікує сигналів на PA2/PA3: ці піни можна залишити вільними для інших функцій (TEMP_ADC, SPINDLE_PWM за Cube) або фізично не розводити. На пульті не ставте перемикач осі в положення Y чи 4.

7. Таймери та периферія (коротко)

  • TIM2 / TIM3 — режим енкодера для PA0/1 та PA6/7 (лінійні датчики), ініціалізація в Src/main.c (linear_encoders_init).
  • TIM1 CH1 — PA8 (крок X); у bringup STEP може бути переведений у GPIO.
  • TIM4 CH1 — PB6 (крок Z).
  • TIM6 — 1 ms тік для енкодера MPG / jog (див. stm32f4xx_it.c).
  • ADC1 — канали на PA2, PA4, PA5 (залежно від конфігурації Cube).
  • I2C2 — PB10/PB11.
  • EXTI0 — PE0 (E-stop).
