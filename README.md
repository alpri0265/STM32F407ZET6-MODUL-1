# STM32F407ZET6-MODUL-1

Прошивка для **STM32F407ZET6** у середовищі **STM32CubeIDE**: керування шліфувальним/координатним модулем (планувальник руху, крокові двигуни, лінійні енкодери, LCD, пульт MPG ZSY1474, аварійний стоп тощо). Репозиторій містить код HAL, користувацьку логіку в `Src/` / `Inc/` і документацію з розводкою в каталозі `docs/`.

---

## Покрокова інструкція: клонування та збірка

### 1. Клонувати репозиторій

У терміналі:

```bash
git clone git@github.com:alpri0265/STM32F407ZET6-MODUL-1.git
cd STM32F407ZET6-MODUL-1
```

Якщо використовуєте **HTTPS** замість SSH:

```bash
git clone https://github.com/alpri0265/STM32F407ZET6-MODUL-1.git
cd STM32F407ZET6-MODUL-1
```

### 2. Відкрити проєкт у STM32CubeIDE

1. Запустіть **STM32CubeIDE**.
2. **File → Open Projects from File System…** (або **Import** залежно від версії).
3. Вкажіть папку `STM32F407ZET6-MODUL-1` і підтвердіть імпорт **MCU project**.

### 3. Обрати конфігурацію збірки

- У **Project Explorer** виберіть проєкт **STM32F407ZET6-MODUL-1**.
- Переконайтеся, що активна потрібна **конфігурація** (наприклад, **Debug** / **Release**) у властивостях проєкту або на панелі збірки.

### 4. Зібрати проєкт

- **Project → Build Project** (або відповідна кнопка «молоток»).

Після успішної збірки з’явиться бінарний файл (наприклад, `.elf` / `.bin` у каталозі збірки Debug/Release).

### 5. Прошити мікроконтролер

1. Підключіть **ST-LINK** до плати та ПК.
2. **Run → Debug** або **Run** (залежно від налаштувань запуску; файл `*.launch` у репозиторії допомагає CubeIDE знайти конфігурацію).

### 1. Перевірити статус

```bash
cd /path/to/STM32F407ZET6-MODUL-1
git status
```

### 2. Додати файли до коміту

```bash

```

Або вибірково: `git add README.md Src/somefile.c`

### 3. Створити коміт

```bash
git commit -m "Короткий опис змін українською або англійською"
```

Якщо Git просить ім’я та email (лише перший раз на цьому ПК):

```bash
git config user.name "Ваше ім'я"
git config user.email "email@example.com"
```

### 4. Відправити на GitHub

Переконайтеся, що **remote** `origin` вказує на ваш репозиторій (SSH):

```bash
git remote -v
```

Має бути щось на кшталт:

`git@github.com:alpri0265/STM32F407ZET6-MODUL-1.git`

Відправка поточної гілки:

```bash
git push -u origin $(git branch --show-current)
```

Наступні рази на тій самій гілці достатньо:

```bash
git push
```

Якщо GitHub «відхиляє» push, спочатку підтягніть зміни:

```bash
git pull --rebase origin $(git branch --show-current)
git push
```

## Розшифровка термінів і скорочень

### Репозиторій і GitHub

| Термін | Що означає |
|--------|------------|
| **Репозиторій (repo)** | Папка з проєктом, за якою стежить **Git**; історія всіх версій файлів. |
| **Git** | Система контролю версій: коміти, гілки, злиття змін. |
| **GitHub** | Веб-сервіс, де зберігають копію репозиторію та спільно працюють над кодом. |
| **README** | Файл `README.md` у корені — «вітрина» проєкту на сторінці GitHub (опис, інструкції). |
| **Коміт (commit)** | Знімок змін з повідомленням; одна «точка» в історії проєкту. |
| **Гілка (branch)** | Паралельна лінія розробки (наприклад, `main` чи `Button`), щоб не змішувати експерименти з основною версією. |
| **push** | Відправка ваших локальних комітів на **GitHub** (оновлення віддаленої копії). |
| **pull** | Завантаження змін з **GitHub** до свого комп’ютера. |
| **origin** | Типова назва **віддаленого** репозиторію (посилання на GitHub). |
| **SSH** | Спосіб підключення до GitHub через ключ (`git@github.com:...`) без введення пароля кожного разу (після налаштування ключа). |
| **HTTPS** | Альтернатива SSH: URL виду `https://github.com/...`; для push часто потрібен **токен доступу**, а не пароль від сайту. |

### Прошивка та STM32

| Термін | Що означає |
|--------|------------|
| **STM32F407ZET6** | Мікроконтролер сімейства STM32F4: ядро **Cortex-M4**, тактова частота до 168 МГц, периферія (таймери, ADC, GPIO тощо). |
| **STM32CubeIDE** | Офіційне IDE від ST на базі Eclipse: редагування, збірка, налагодження, CubeMX-інтеграція. |
| **HAL** | **Hardware Abstraction Layer** — бібліотека ST для ініціалізації та роботи з периферією (однаковий стиль API для різних STM32). |
| **ST-LINK** | Програматор/налагоджувач від STMicroelectronics (USB до ПК, SWD до MCU). |
| **Прошивка (flash)** | Запис скомпільованої програми у внутрішню флеш-пам’ять МК. |
| **MPG** | **Manual Pulse Generator** — ручний пульт імпульсів для покрокового руху по осях (у проєкті — пульт **ZSY1474**). |
| **GPIO** | Загальні цифрові входи/виходи мікроконтролера (кнопки, крок/напрям, сигнали з пульта тощо). |
| **I2C** | Послідовна шина для зв’язку з периферією (наприклад, дисплей або розширувачі портів — залежно від схеми). |
| **EXTI** | Зовнішні переривання по зміні рівня на піні (наприклад, аварійний стоп). |
